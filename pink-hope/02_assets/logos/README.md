# شعارات الجهات — Logo slot

**No logo files were supplied with the footage, so the end card currently shows no logos.**
No logo has been recreated, redrawn, or cropped out of the footage.

## How to add the official logos

1. Put the original logo files here (transparent PNG preferred, at least 600 px tall).
2. Create `order.txt` in this folder with one file name per line, in the official order.
   The first line appears on the **right**, following Arabic reading order:

   ```
   libyan-union-against-cancer.png
   women-support-office-ajeelat.png
   ```

3. Re-run `04_project/build.sh`.

What the renderer does to logos: it scales each one **uniformly** (no stretching) to a shared
height, keeps original colours and transparency, lays them out with equal spacing on the
calm end card, and fades them in gently. No rotation, glow, recolouring or cropping.
