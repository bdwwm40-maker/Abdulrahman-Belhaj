# إعدادات المونتاج المحفوظة: «قطعات الدوائر المتطابقة على دقّات الساعة»

## 1) نتيجة تحليل الفيديو المرجعي
| الخاصية | القيمة |
|---|---|
| المدة | 7.05 ثانية |
| الأبعاد | 720×1280 (عمودي 9:16)، والمونتاج نفسه كادر 16:9 في النصف العلوي |
| معدل الإطارات | 23.976 fps |
| الترميز | H.264 High + صوت AAC ستيريو 44.1kHz |
| الإيقاع | قطعة كل **0.5 ثانية** (يعادل 120 BPM)، «قطعة واحدة مع كل دقّة» |
| الألوان | دافئة سينمائية، تباين ناعم، تشبّع أقل قليلًا، تظليل أطراف (vignette) |

## 2) بنية المونتاج (التسلسل الزمني)
1. **0.00 – 2.29 ث | المقدمة:** يد تكتب بالقلم على دفتر، مع صوت القلم وقلب الصفحة.
2. **≈2.3 ث | Mask Reveal:** قلب الصفحة يُستخدم كقناع يكشف لقطة العين.
3. **2.42 – 6.80 ث | Match Cuts:** في كل لقطة **جسم دائري في منتصف الكادر** بنفس حجم قزحية العين تقريبًا:
   العين ← مصباح دائري ← ساعة حائط ← كرة أرضية ← عدسة كاميرا ← فتحة الغيتار ← شعلة الغاز ← إبريق شاي يغلي ← فنجان شاي.
4. **6.80 – 7.05 ث | الخاتمة:** نعود إلى العين فتُغلق (Adjustment Layer لإبراز تفاصيل العين) ثم انتهاء.

## 3) طبقات الصوت (Sound Design)
- **Riser:** صوت يتصاعد طوال الفيديو ويتوقف عند إغلاق العين.
- **Ticks:** دقّة ساعة مع كل قطعة.
- **مؤثر لكل لقطة:** كرة تدور، عدسة، غيتار، شعلة، غليان الشاي.
- **العين تُفتح / العين تُغلق** في البداية والنهاية.
- **قلم + قلب صفحة** في المقدمة.

## 4) قواعد التصوير لتحصل على نفس الأسلوب
- صوّر كل جسم دائري **في منتصف الكادر تمامًا** من زاوية علوية أو أمامية.
- اجعل الدائرة بقطر 35–45% من ارتفاع الكادر تقريبًا.
- صوّر 3 ثوانٍ على الأقل لكل لقطة، بإضاءة دافئة وعمق ميدان ضحل.

## 5) طريقة إنشاء مونتاج بنفس الطريقة تلقائيًا
1. ضع مقاطعك في مجلد `clips/` بنفس أسماء ملف `project_example.json` (أو عدّل الأسماء داخله).
2. يمكنك تحديد بداية كل لقطة (`in`) وتكبيرها (`zoom`) لمطابقة حجم الدائرة، وإضافة مؤثر صوتي (`sfx`) أو موسيقى (`music`).
3. شغّل الأمر:
   ```bash
   python3 montage/make_montage.py montage/project_example.json
   ```
4. لإخراج عمودي (تيك توك / ريلز) اجعل `"vertical": true`.

السكربت يطبّق تلقائيًا: القص على الإيقاع، والانتقال بالقناع، والتلوين الدافئ، وصوت الـ Riser، ودقّات الساعة، والإغلاق في النهاية، وضبط مستوى الصوت على ‎-14 LUFS.

الإعدادات الكاملة بصيغة قابلة لإعادة الاستخدام موجودة في: `preset_circle_match_cut.json`
