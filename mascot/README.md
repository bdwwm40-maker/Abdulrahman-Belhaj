# الشخصية الرسمية — الوكالة الوطنية للجهود التطوعية للشباب

شخصية ثلاثية الأبعاد (Premium 3D Emoji Character + Professional Institutional Mascot)
بالزي الليبي التقليدي، وعلى صدرها الأيسر شعار الوكالة.

> **ملاحظة مهمة:** صورة الشخص المرجعية لم تصل بعد، لذلك الوجه الحالي **وجه مؤقت**
> لشاب ليبي عام. عند وصول الصورة يُعدَّل الوجه فقط ويبقى كل شيء آخر كما هو (انظر «الخطوة التالية»).

## الملفات النهائية (`final/`)

| الملف | الاستخدام |
|---|---|
| `mascot-full-body.png` | النسخة الرئيسية 3072×4096 بخلفية استوديو رمادية فاتحة |
| `mascot-full-body-1536.jpg` | نسخة خفيفة للمعاينة والمنشورات |
| `mascot-cutout.png` | الجسم كاملاً بخلفية شفافة (للإعلانات والفيديو والملصقات) |
| `mascot-emoji.png` | رأس وكتفان 1024×1024 بخلفية شفافة (Emoji / Sticker) |
| `mascot-avatar.png` | صورة دائرية 1080×1080 على أزرق الوكالة (صورة حساب) |
| `mascot-identity-sheet.png` | لوحة هوية الشخصية: الشخصية + الشعار + القيم + ألوان الهوية |

ألوان الهوية المستخرجة من الشعار: أزرق `#006CB4`، أخضر `#78B424`، برتقالي `#E46C0C`، داكن `#181818`.

## الشعار

- الشعار في `references/agency-logo.png` كما سُلِّم دون أي تعديل.
- `logo/agency-logo-transparent.png` هو الشعار نفسه بعد إزالة الخلفية البيضاء الخارجية فقط.
- الشعار **لم يُرسم بالذكاء الاصطناعي**؛ وُضع بالبرمجة (`tools/place_logo.py`) من الملف الأصلي:
  تكبير/تصغير بنسب ثابتة، على شارة بيضاوية مطرزة بلون كريمي، مع ظل وملمس القماش.
  فرق ألوان الشعار على السترة عن الأصل ≤ 5/255 لكل قناة (غير مرئي).
- الموضع: **الصدر الأيسر للشخصية** (يظهر على يمين الصورة للناظر).

## كيف صُنعت

1. ثلاث نسخ أولية بثلاثة نماذج (المجلد `variants/`: أ، ب، ج) ثم تقييم مستقل لكل نسخة
   (دقة الزي، الأسلوب، الجودة التقنية، ناقد).
2. النسخة النهائية وُلِّدت بدمج أسلوب (ب) ثلاثي الأبعاد مع دقة زي (ج) ومرجع الزي الأصلي.
3. إزالة أثر مستطيل باهت على الصدر (`tools/remove_outline.py`) ثم وضع الشعار.
4. قص الخلفية محلياً (`tools/make_cutout.py`) ثم بناء الملفات المشتقة (`tools/build_assets.py`).

إعادة بناء الملفات المشتقة بعد أي تعديل على النسخة الرئيسية:

```bash
python3 tools/place_logo.py variants/final-base-no-logo.png final/mascot-full-body.png --cx 1780 --cy 1045 --width 150
python3 tools/make_cutout.py final/mascot-full-body.png final/mascot-cutout.png
python3 tools/build_assets.py
```

يتطلب: `pillow`، `numpy`، `opencv-python-headless`، `rembg[cpu]`. الخط: Cairo (رخصة OFL، Google Fonts).

## الخطوة التالية

- إرسال صورة واضحة للشخص (من الأمام، إضاءة جيدة، وجه غير مغطى) لتعديل الوجه ليطابقه
  مع الحفاظ على الزي والشعار والأسلوب.
- بعد اعتماد الشكل: وضعيات إضافية للملصقات (تحية، إشارة إعجاب، تفكير…) بنفس الشخصية.
