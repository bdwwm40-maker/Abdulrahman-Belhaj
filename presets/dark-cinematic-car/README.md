# إعدادات المونتاج — Dark Cinematic Car Reel

إعدادات مستخرجة من فيديو ريلز لسيارة سوداء مطفية داخل موقف سيارات (18.9 ثانية: 15.9 ثانية مونتاج + 3 ثوانٍ شاشة نهاية تيك توك).

## المشروع
| الإعداد | القيمة |
|---|---|
| المقاس | 9:16 عمودي — 1080×1920 (الأصل 576×1024) |
| معدل الإطارات | 30 fps |
| الألوان | Rec.709 |
| التصدير | H.264 High، صوت AAC ‏44.1kHz ستيريو |

## الإيقاع والقصّات
- **المقدمة (0 → 1.53 ث):** لقطة واسعة، أشرطة سوداء تنغلق من الأعلى والأسفل حتى شريط سينمائي رفيع (~2.35:1)، ثبات، ثم تنفتح مع أول قصّة.
- **القصّات:** 1.53 · 2.27 · 3.07 · 3.87 · 4.57 · 6.10 · 6.90 · 7.63 · 8.40 · 9.07 · 9.23 · 10.70 · 13.03
- **متوسط طول اللقطة:** ~0.75 ث، القص على الإيقاع (beat).
- **مؤثرات صغيرة:** وميض/تقطيع 2–3 إطارات عند 8.4 و 9.2 ث.
- **لقطة البطل:** مسكة أطول (10.7 → 13.0 ث) قبل النهاية.
- **النهاية:** تلاشي للأسود عند ~15.9 ث مع انتهاء الموسيقى.

## قائمة اللقطات
واسعة أمامية ← ضوء أمامي منخفض ← جنط وكاليبر أحمر (ماكرو) ← ضوء خلفي ← جانب ← عوادم ← أمامية متمركزة ← زاوية مائلة (Dutch) ← الداخلية عبر الباب ← خلفية متمركزة ← تفاصيل الباب/المرآة ← المصد ← جنط بزاوية ثانية ← ضوء DRL ← واسعة مائلة.

**التصوير:** جيمبال، دفع بطيء ودوران، زوايا منخفضة جداً، ميلان 10–20°، يفضّل 60fps.

## تدريج الألوان (Low-key Dark Matte + Red Pop)
القيم المقاسة: متوسط الإضاءة 42.7/255، تشبع منخفض جداً.
1. التعريض ‎-0.7 إلى ‎-1.0
2. التباين ‎+20، سحق الأسود (Shadows ‎-30)
3. الهايلايت ‎-20
4. التشبع العام ‎-70 إلى ‎-80
5. HSL: إبقاء الأحمر (‎+20) وإطفاء باقي الألوان
6. لمسة زرقاء باردة في الظلال
7. Vignette ‎-15

## الصوت
- مسار موسيقى واحد (Phonk / Deep)، مضغوط بقوة.
- الصوت: ‎-14 LUFS، الذروة ‎-1 dBTP، مدى ‎3.7 LU.
- بدون نصوص على الشاشة.

## الملفات
- `preset.json` — كل الإعدادات بصيغة قابلة للقراءة آلياً.
- `apply.sh` — يطبّق المقاس والتدريج وأشرطة المقدمة وتسوية الصوت عبر ffmpeg على مقطع جاهز: `./apply.sh input.mp4 output.mp4`

## تحويل الصور إلى ريلز بنفس الإعدادات
`photos_to_reel.py` يبني فيديو 9:16 من صور ثابتة بنفس الإيقاع والتدريج والمقدمة:
```
python3 photos_to_reel.py shots.json output.mp4 [music.mp3]
```
- `shots.json`: قائمة اللقطات (الصورة، المدة، مركز القص، التقريب، الدفع، الميلان، الوميض). مثال: `example_bmw_m5_shots.json`.
- بدون ملف موسيقى يولّد إيقاعاً داكناً 80 BPM متزامناً مع القصّات.

## تحويل كل صورة إلى فيديو ثم المونتاج
1. `photo_to_clip.py` يحوّل كل صورة إلى مقطع 4 ثوانٍ: يفصل السيارة عن الخلفية (rembg) ويحرّك الطبقتين بسرعتين مختلفتين (عمق ثلاثي الأبعاد) مع نبض للأضواء.
   ```
   pip install "rembg[cpu]" opencv-python-headless
   python3 photo_to_clip.py clips IMG_*.jpeg
   ```
2. `photos_to_reel.py` يقبل مقاطع الفيديو أيضاً (يأخذ وسط كل مقطع): مثال `example_bmw_m5_clips.json`.
   ```
   python3 photos_to_reel.py example_bmw_m5_clips.json reel.mp4 [music.mp3]
   ```
